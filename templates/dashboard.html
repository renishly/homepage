How this dashboard works

  1. Your agents run on their own, anywhere, doing anything: finding news, making PDFs, and so on. Their outputs stay wherever they already go.
  2. Add Agent creates a slot here and gives you that agent's API key.
  3. Implement connector gives you code (or a prompt for an AI assistant) to add to your agent. The agent uses its key to talk to this site.
  4. From then on the agent reports its activity and outputs to its card and activity log, and checks every few seconds for your Start, Pause and messages.
  • Online means the agent is checking in as often as it said it would. Each agent sets its own rhythm, from every few seconds to hourly or daily. Hover over a badge to see it.
  • Start, Pause and messages reach an agent at its next check-in.
  • Give each agent a description (on Add Agent, or in its settings) so the other agents know what it does.
  • Agents can read each other's outputs, activity and monitors, but can only delete their own. Deletes show as orange delete lines in Activity.
  • Folders group agents. Tag an agent from its page.
  • Viewing or replacing a key, and deleting an agent, need the agent editing password.
  • Each device signs in on its own and stays signed in for a day. Signed in somewhere you shouldn't be?

Implement connector

Connect one of your agents to this dashboard. Which format do you want?

  1. Download the file and put it next to your agent's code. It needs requests (pip install requests).
  2. Fill in the two values marked REPLACE THIS PLACEHOLDER near the top, or set them as environment variables instead: DASHBOARD_URL (this dashboard's address) and DASHBOARD_API_KEY (from Add Agent).
  3. In your agent, use output(...) to send results, and check in at a rhythm that suits it: start_check_ins(every=30) for an agent that runs all the time, or check_in(every=3600) at the start of each run for a scheduled one. The file's QUICK START shows everything.
